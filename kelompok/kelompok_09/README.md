OneBlood : Sistem Donor Darah Terpadu

Sistem Donor Darah Terpadu OneBlood merupakan Sistem Donor Darah yang memudahkan masyarakat untuk mendapatkan informasi terkait donor darah,stok darah, dan kegiatan donor darah di sekitar mereka. 

Sistem ini memiliki 3 aktor yaitu pendonor, admin, dan petugas
Admin: admin bertugas untuk melakukan manajemen dan juga pendataan laporan, dimana terdapat fitur manajemen anggota supaya admin dapat memanajemen keanggotaan dan laporan supaya dapat melihat terkait laporan jumlah kantong darah tiap bulannya.
pendonor : pendonor disini dapat melakukan donor dimana pendonor perlu dapat melakukan booking terkait jadwal donor, lalu dapat dilihat hasil skrining dan juga pendonor memiliki kartu donor dimana kartu donor berisikan diwayat donor itu sendiri.
petugas : petugas memiliki beberapa fitur yaitu dapat menambahkan event, lalu dapat memonitoring terkait suhu ruang pendigin, skrining, memberikan sos_darurat, kapan kantong darah expired, dan distribusi kantong darah.
