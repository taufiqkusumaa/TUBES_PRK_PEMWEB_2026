# ADVOKITA Design System

## Visual direction

- Official, calm, and accessible campus legal-aid portal.
- Primary color: crimson `#a80f19`.
- Dark crimson: `#7e000a`.
- Canvas: `#f7f8f8`.
- Border: `#e2e5e7`.
- Body typeface: Inter.
- Heading typeface: Plus Jakarta Sans.

## Layout

- Bootstrap container controls the primary page width.
- Desktop content uses Bootstrap rows and columns.
- Mobile navigation is a fixed three-item bar.
- Cards use a 6px radius, light border, and no heavy shadow.
- Forms use Bootstrap form controls and validation attributes.

## Components

- `site-header`: shared desktop header.
- `main-nav`: primary navigation.
- `content-card`: status and schedule panels.
- `report-cta`: bordered call to action.
- `report-form`: complaint submission form.
- `history-list`: report history collection.

## Responsive rules

- Desktop breakpoint follows Bootstrap `md` and `lg`.
- At widths below `768px`, desktop navigation is replaced by the fixed mobile navigation.
- Multi-column content stacks vertically on small screens.
