
# RANCANGAN UI APLIKASI KLIKOBAT

## 1. Pendahuluan

Rancangan UI ini dibuat sebagai panduan tampilan untuk fitur modal edukasi obat dan halaman admin pada aplikasi KlikObat.

## 2. Konsep Desain

Desain menggunakan konsep sederhana, bersih, dan mudah digunakan.

Warna utama:
- Hijau tua: #245c46
- Hijau: #398363
- Putih: #ffffff
- Abu-abu muda: #f4f7f5

Jenis huruf: Arial atau sans-serif.

## 3. Rancangan Modal Edukasi Obat

Modal edukasi digunakan untuk menampilkan informasi detail obat ketika pengguna memilih tombol Detail Obat.

Komponen:
1. Judul Detail Edukasi Obat.
2. Nama obat.
3. Indikasi atau kegunaan obat.
4. Aturan pakai.
5. Peringatan penggunaan.
6. Informasi stok.
7. Tombol tutup.

Alur penggunaan:
1. Pengguna memilih tombol Detail Obat.
2. Sistem mengambil ID obat.
3. JavaScript meminta data ke API detail obat.
4. Sistem menampilkan informasi obat dalam modal.
5. Pengguna menutup modal setelah selesai membaca.

## 4. Rancangan Dashboard Admin

Dashboard admin dirancang menggunakan sidebar dan area konten utama.

Komponen:
- Header: menampilkan judul halaman dan identitas admin.
- Sidebar: berisi navigasi dashboard, data obat, data kategori, pengaturan, dan keluar.
- Konten utama: menampilkan informasi dan tabel pengelolaan.
- Footer: menampilkan informasi hak cipta aplikasi.

## 5. Responsivitas

Tampilan dirancang agar dapat menyesuaikan ukuran layar.

- Laptop: sidebar berada di sebelah kiri dan konten di sebelah kanan.
- Tablet: ukuran sidebar dan konten menyesuaikan layar.
- HP: sidebar dan konten disusun secara vertikal.

## 6. Kesimpulan

Rancangan UI ini menjadi panduan awal dalam pengembangan modal edukasi obat dan halaman admin KlikObat. Implementasi dan penyesuaian dilakukan berdasarkan kebutuhan integrasi aplikasi.
